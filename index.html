About this project

This assistant uses a Fuzzy Cognitive Map (FCM) to model how body metrics, fitness level, and goals influence exercise recommendations. Values are grounded in expert-style rules (not random weights), and the system returns clear, actionable suggestions—not only raw numbers.

!

Please read before you start

Sliders are self-reported estimates (1 = low, 10 = high). This tool does not replace medical advice. If you have pain, injury, or a health condition, consult a professional before training.
